# Algorithm Optimization Assignment

Solutions for:
1. Sum of all primes below N
2. Count pairs with a given sum
3. K-th smallest pairwise sum

Files:
- `problem1_primes.py`
- `problem2_pairs.py`
- `problem3_kth_sum.py`

Run from the terminal:
```bash
python problem1_primes.py
python problem2_pairs.py
python problem3_kth_sum.py
```

The programs include the naive/optimized approaches where practical and timing code.
